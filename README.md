# 🏏 Sports Academy Bandra

A modern, responsive React website for **Sports Academy Bandra**, a cricket coaching academy in Bandra, Mumbai, Maharashtra, India.

The website showcases cricket training programs, coaches, achievements, a photo gallery, videos, student testimonials, and contact information.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Sticky navigation with a mobile hamburger menu
- Cricket coaching programs
- Coach profiles and achievements
- Photo gallery with lightbox
- Cricket videos section
- Student testimonials
- Contact form with client-side validation
- Smooth scrolling and scroll animations
- SEO meta tags and structured data
- Lazy-loaded images for better performance

## 🛠️ Tech Stack

- React 18
- Vite 8
- JavaScript (ES6+)
- HTML5
- CSS3
- CSS Grid and Flexbox

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

```bash
git clone https://github.com/Shafiquemulla/sports-academy.git
cd sports-academy
npm install
npm run dev
```

Open the local URL shown in your terminal.

### Production Build

```bash
npm run build
npm run preview
```

The production-ready files will be generated in the `dist/` directory.

## 🎨 Design System

The website uses CSS custom properties defined in `src/index.css`.

- Primary background: Dark navy
- Accent color: Gold/amber
- Secondary color: Deep blue

Update the CSS variables in `src/index.css` to customize the theme.

## 📝 Customization

Update the following files to customize the website, if they exist in your project:

- `src/data/programs.js` — coaching programs
- `src/data/coaches.js` — coach details
- `src/data/gallery.js` — gallery images
- `src/data/videos.js` — video information
- `src/data/testimonials.js` — student testimonials
- `src/components/Contact.jsx` — contact details

Replace sample information with verified academy details before publishing.

## 📱 Responsive Design

The website is designed to work across desktop, laptop, tablet, and mobile screen sizes.

Test the layout at widths of 320px, 375px, 390px, 430px, 768px, and 1280px.

## 🔍 SEO

The project includes SEO metadata and structured data intended to help search engines understand the website. Search ranking is not guaranteed.

## ⚠️ Important Notes

- Verify coach profiles, testimonials, and statistics before publishing.
- Replace placeholder video URLs with valid YouTube embed URLs.
- Replace sample images with genuine academy photos where possible.
- The contact form requires a backend or email service to deliver messages. Client-side validation alone does not send emails.
- Add a real phone number and address only after verifying the details.
